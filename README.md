# Sona Visualizer

手持ちの音源からビジュアライザー映像を作り、MP4で保存できる Windows アプリです。音楽プレイヤー画面にも切り替えられます。

## 起動

1. `SonaVisualizer.exe` をダブルクリックします。専用ウィンドウが開きます。
2. ビジュアライザー画面では音源を選び、テーマや表示を調整して「曲の最初から録画」を押します。
3. 音楽プレイヤー画面は、右上の「♫ ミュージックプレイヤー」で切り替えます。

起動時にGitHubの公開更新情報を確認し、新しいバージョンがあれば自動で適用して再起動します。オフラインの場合や更新情報を取得できない場合は、現在のバージョンで起動します。更新ファイルのSHA-256も照合します。

Downloads で使う場合は、Portable ZIP を Downloads に保存し、右クリックして「すべて展開」を選んでください。展開されたフォルダー内で `SonaVisualizer.exe` を起動します。EXEだけをZIPから取り出すと、必要な画面ファイルがなく起動できません。

初回起動時に必要なものは Windows 10/11、Microsoft Edge または Google Chrome、H.264対応の FFmpeg です。FFmpeg はこのPCにインストールされ、PATHから利用できる必要があります。

## ビジュアライザーと録画

- タイトル欄で Enter を押すと改行できます。動画上でタイトルをドラッグして配置します。
- プレビュー上の各パネルもドラッグで移動できます。右下の小さな角ハンドルをドラッグするとサイズを変えられます。
- かわいい、パステル、深海、サイバーパンク、メカ、幽霊屋敷、血の月、呪われた森など32種類のテーマを選べます。背景色、アクセントカラー、サブカラーを個別に調整できます。
- 背景デザインは星空、星雲、オーロラ、花びら、深海、森、メカグリッド、CRT、ホラーの霧、血の月、火の粉から選べます。「テーマに合わせる」にすると、テーマごとの背景演出に切り替わります。
- 出力は1080pまたは720p、30または60 FPSのMP4（H.264 + AAC）です。
- プレビュー音量の調整は録画音量に影響しません。
- 「保存先フォルダーを選ぶ」で出力先を指定できます。未指定なら録画後に「MP4をダウンロード」を押してください。変換した映像はアプリフォルダー内の `renders` にも保存されます。
- 録画中も専用ウィンドウを閉じずにお使いください。別アプリへ切り替えた場合も録画を続けやすい設定で起動します。Windowsがスリープすると録画は止まります。

## ミュージックプレイヤー

- 音源を複数選択するかフォルダーを追加できます。フォルダーや複数フォルダーをドロップすると、階層内をたどって音声ファイルだけを最大10000曲まで読み込みます。
- プレイリストは名前順またはランダム順にできます。再生、前後の曲への移動、シークに対応します。
- フル再生、または曲の開始位置を指定して15、20、25、30秒だけ再生できます。ビジュアライザー画面で録画する場合は、選んだ区間をMP4にできます。
- YouTube URLは公式の埋め込みプレイヤーで再生します。YouTube動画から音源を取り出したり、YouTube再生をMP4録画したりはできません。MP4録画には手持ちの音源ファイルを使ってください。現在、YouTubeプレイリストURLは未対応です。

ブラウザーで動画再生が制限されている場合、その動画は埋め込みできないことがあります。YouTubeの利用条件は、サービスが許可した方法以外でのダウンロード等を制限しています。詳細は[YouTube利用規約](https://www.youtube.com/t/terms)をご確認ください。

## ファイルについて

- `SonaVisualizer.exe`：アプリ起動用。ピンクと紫の猫ヘッドホンアイコンを埋め込み済みです。アプリ左上にも同じアイコンを表示します。
- `SonaVisualizer.png`：アプリ左上に表示するアイコン画像
- `index.html`：アプリ画面
- `server.js` / `server.ps1`：EXEを使わずに起動するときの補助サーバー
- `start.bat`：EXEを起動するショートカット用バッチ
- `SonaVisualizer.ico`：EXEと同じアイコンファイル
