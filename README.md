# Sona Visualizer

手持ちの音源からビジュアライザー映像を作り、MP4で保存できる Windows アプリです。音楽プレイヤー画面にも切り替えられます。

[最新のPortable ZIPをダウンロード](https://github.com/yuuma1on/sona-visualizer/releases/latest)

## 起動

1. `SonaVisualizer.exe` をダブルクリックすると、専用ウィンドウが最大化で開きます。タイトルバーのボタンで通常の大きさに戻せます。
2. ビジュアライザー画面では音源を選び、テーマや表示を調整して「曲の最初から録画」を押します。
3. 音楽プレイヤー画面は、右上の「♫ ミュージックプレイヤー」で切り替えます。
4. スペースキーで再生と一時停止を切り替えます。上部の音量スライダーと消音ボタンは、どちらの画面でも使えます。

起動時にGitHubの公開更新情報を確認し、新しいバージョンがあれば自動で適用して再起動します。オフラインの場合や更新情報を取得できない場合は、現在のバージョンで起動します。更新ファイルのSHA-256も照合します。

Portable ZIP を右クリックして「すべて展開」を選び、展開先の `SonaVisualizer.exe` を起動します。`app` と `runtime` はEXEと同じ場所に置いてください。v1.0.5以前からこの構成へ移る場合は、新しいZIPを別フォルダーへ展開してから使います。録画済みの動画は元の `renders` にあります。

初回起動時に必要なものは Windows 10/11、Microsoft Edge または Google Chrome、H.264対応の FFmpeg です。FFmpeg はこのPCにインストールされ、PATHから利用できる必要があります。

## ビジュアライザーと録画

- タイトル欄で Enter を押すと改行できます。「表示」で曲名の文字サイズと表示幅を変え、動画上でタイトルをドラッグして配置します。
- 「表示 → 配置を見比べる」から横20種類、縦22種類の配置を選べます。「配信の待機画面」「ジャケットと波形」「左右の聴き比べ」などを追加しました。縦長では右と下に余白を取った「ショート動画向け」も選べます。各パネルはドラッグで移動し、右下のハンドルで大きさを変えられます。
- 表示パネルは15種類です。ジャケットカード、左右の波形、帯域レベルの履歴、帯域レベル、ステレオ相関は「表示」で個別にチェックして使えます。
- 「テーマを見比べる」で69種類の映像テーマをプレビューできます。「見本の画面比」から横長・縦長を切り替えると、背景とビジュアライザーの見え方を確認できます。
- かわいい系9種の背景とフレームを描き直しました。Kawaii Popはヘッドホンベアのシール帳、Cherry Sodaは喫茶店のチェリーフロート、Lavender Dreamは月のモビールです。
- 「背景デザイン」から83種類を選べます。夜景、レトロ、メカ、ノスタルジー、幻想系の背景や音に連動する演出を見直しました。背景色、アクセントカラー、サブカラーを個別に調整できます。
- 「Sona Kitty — ソナねこ」を選ぶと、ソナねこが曲に合わせて動くリスニングルームが表示されます。初期の「バランス」配置からこのテーマを選ぶと、全身が見える「ソナねこを見せる」配置になります。他のテーマと組み合わせるときは「背景デザイン」で「ソナねこのリスニングルーム」を選べます。
- 「曲名のフォント」では、同梱の38書体とWindows標準から選べます。同梱のうち13書体は日本語対応です。選んだ書体は動画タイトル、曲情報、プレイリストに反映されます。
- 「保存」タブからテーマ、背景、色、表示パネルの配置とサイズ、フォントを名前付きで保存できます。
- 「音源」またはプレイヤーの「曲ごとの設定」で「この曲に保存」を押すと、手持ちの音源ごとにジャケット・タイトルの改行・テーマ・配置などを保存します。同じ音源を開くと適用され、「呼び出す」でも手動で戻せます。設定と画像はこのPCに保存されます。
- 「画面比」で横16:9または縦9:16を選べます。縦長の出力は1080 × 1920または720 × 1280、横長の出力は1920 × 1080または1280 × 720です。30または60 FPSのMP4（H.264 + AAC）で保存できます。
- プレビュー下の「録画範囲 A–B」を開き、曲を聴きながら「現在位置を A」「現在位置を B」で開始点と終了点を指定できます。秒数の直接入力にも対応します。「A–B を録画」を押すとAから録画してBで自動停止し、その区間をMP4にします。
- 「デザイン → ジャケット背景」で、ぼかし、ジャケットを飾る、ジャケットの色で背景を作る、の3種類から選べます。音源を切り替えると、その曲の画像に変わります。
- プレビュー音量の調整は録画音量に影響しません。
- 「保存先フォルダーを選ぶ」で出力先を指定できます。未指定なら録画後に「MP4をダウンロード」を押してください。変換した映像はアプリフォルダー内の `renders` にも保存されます。
- 録画中も専用ウィンドウを閉じずにお使いください。別アプリへ切り替えた場合も録画を続けやすい設定で起動します。Windowsがスリープすると録画は止まります。

## ミュージックプレイヤー

- 音源を複数選択するかフォルダーを追加できます。フォルダーや複数フォルダーをドロップすると、階層内をたどって音声ファイルだけを最大10000曲まで読み込みます。
- プレイリストは名前順またはランダム順にできます。再生、前後の曲への移動、シークに対応します。
- 「プレイヤーデザイン」から8種類のデザイン、または映像テーマとの連動を選べます。MP3に埋め込まれたJPEG、PNG、WebPの表ジャケットを表示できます。
- 「ジャケット画像を選ぶ」で現在の曲にPNG・JPEG・WebPを指定できます。「元のジャケットに戻す」で解除できます。この指定は現在読み込んでいるプレイリスト内で有効です。
- 曲の横のチェックを付けて「選択分を削除」を押すと、複数曲をまとめて外せます。全削除と各曲の「×」も使えます。ディスク上の音源ファイルは保持されます。
- フル再生、または曲の開始位置を指定して15、20、25、30秒だけ再生できます。ビジュアライザー画面で録画する場合は、選んだ区間をMP4にできます。
- 「YouTubeを再生リストに追加」は、公式埋め込みプレイヤーでの再生に使います。

## Discordで映像スタジオを共有

1. 映像スタジオの「共有用ウィンドウ」を押し、映像だけのウィンドウを開きます。
2. Discordで画面共有を開き、「Sona Visualizer — 共有用映像」のウィンドウを選びます。編集画面を操作すると、共有用の映像にも反映されます。
3. 共有先にも音を流したい場合は、「音源 → 共有用ウィンドウでも音を出す」をオンにして、Discordで音声共有を有効にします。音が出ない場合は共有用ウィンドウの映像を一度クリックしてください。
4. スタジオで `1`（待機）、`2`（再生中）、`3`（終了）を押すと、再生を続けたまま共有映像を切り替えられます。「文言を編集」で待機・終了の見出しと補足を変更できます。録画中に切り替えたシーンもMP4に入ります。

## ダウンロードと形式変換

1. ミュージックプレイヤーに切り替えます。
2. YouTubeの動画URLかSoundCloudの曲ページのURLを貼り付けます。手持ちの音源を変換するときは、URL欄を空にしてプレイリストで曲を選びます。
3. MP3、MP4、OGGから選んで「ダウンロード」を押します。音声だけの曲をMP4で保存すると、黒背景の動画になります。

リンクからの取得には、保存が許可されている公開中の単体コンテンツを使ってください。対応範囲は最大2時間、512 MBです。SoundCloudのDiscoverやプレイリストを開いた場合は、曲ページを開いてからURLをコピーしてください。

リンクからの保存には `runtime` 内の `yt-dlp.exe` を使用し、YouTubeでは `deno.exe` も使います。録画と変換にはFFmpegが必要です。変換・ダウンロード機能は `SonaVisualizer.exe` から起動して使います。

## ファイルについて

- `SonaVisualizer.exe` と `start.bat`：どちらからでも起動できます。
- `app`：画面、テーマ、フォント、アイコン。
- `runtime`：ダウンロード用ツールと補助サーバー。
- `docs`：使い方とライセンス。
- `renders`：MP4の保存先。初回起動時に作成します。
- `logs`：起動ログ。初回起動時に作成します。
